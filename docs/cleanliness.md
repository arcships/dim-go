# 干净检查表

Status: **正在执行**（2026-11-20）
用途：这一轮不按"范围"结案，按"干净"结案。下面每一条都要能指着代码与运行证据说"没有"。

## 1. 没有残留

- [ ] 连接模式下屏上不出现任何样例数据（`sample*`、`demo*`、写死的名字/路径/命令/ID）
- [ ] 没有"看起来能用但点了没反应"的控件：要么真做事，要么禁用并写原因
- [ ] 没有只改本地状态、不发请求却回执"已成功"的动作
- [ ] 没有开发口径上屏（"等事实""未进快照""缺协议""本版不做"）
- [ ] 没有 `TODO` / `FIXME` / `XXX` / `暂未` / `临时` 遗留
- [ ] 没有调试/探针文件（`zz_*`、`*tmp*`、`cmd/tmp*`、临时截图脚本）

## 2. 没有重复与死代码

- [ ] 同一函数/常量只有一处定义（无重复声明、无平行实现）
- [ ] 没有未被引用的常量、函数、字段（编译器 + `golangci` 级别的人工扫）
- [ ] 没有两套做法并存（同一个交互一处行内、一处弹窗；同一个文案两处不同）

## 3. 一致性

- [ ] 同一事实在不同屏的措辞一致（退出码、工作区、权限档、模型名、时间格式）
- [ ] 文档、需求状态列、代码三者一致（改一处必须改三处）
- [ ] 空态 / 读取中 / 错误态 / 无权限 四态在每个数据面上都分得开

## 4. 可验证

- [ ] `go build ./... && go vet ./... && go test ./... -count=1` 全绿，连跑三次不飘
- [ ] `./scripts/ui-lint` 与 `--seeds` 全绿
- [ ] 金图与当前代码一致（`-update` 后无残留差异）
- [ ] 关键路径有端到端用例：发消息、终端、右栏面板、设置写事实
- [ ] 真机走查：双击 → 连上 → 开会话 → 发消息 → 审批 → 搜索 → 终端 → 设置

## 5. 收口动作

- [ ] 重出发布包并在干净目录复验
- [ ] 仓库工作区干净、远端同步、无未跟踪文件

## 1 判定规则

一句话：**这个字是谁说的？**

| 谁说的 | 判定 | 处置 |
|---|---|---|
| 用户说的 | 内容 | 原样呈现，不缩不省（用户消息、草稿、队列项） |
| 事实说的 | 内容 | 原样呈现（路径、命令、结果词、失败原因、会话标题） |
| 我们替系统说的 | 界面语 | 按四变量选形式（纯图标 / 图标+文字 / 纯文字 / 样式） |

两条落地约定：

1. **内容字符串允许「看起来像状态词」**：`完成` / `失败` 出现在**一次操作的结果**里是内容（U1 C3），不因为它是状态词就删。
2. **界面语不因为「简短」就免检**：`输入`、`允许一次` 也是界面语，只是它们落在「纯文字（短句）」这一档，理由写在 `U2-forms.md`。

## 2 边界案例

| 案例 | 判定 | 依据 | 说明 |
|---|---|---|---|
| 组头里的对象名（`composer.go`、`go test ./...`） | 内容 | C2 | 数据保真；组头的动作词（读取/改动/执行）是 C1，同属内容 |
| 命令原文（`rm -rf ./tmp/*`） | 内容 | C2 / D1 | 审批卡上必须原样给；不缩写、不加引号 |
| 路径（`internal/ui/composer.go`、`tmp/`） | 内容 | C2 | 可以在行尾截断，但悬停给全量 |
| 失败原因（`权限不足，命令没有执行`） | 内容 | C7 | 结论 + 原因的分工：原因来自事实 |
| 审批的影响说明 | 内容 | D2 | 事实给的范围描述；不写「影响：」这类标签（位置已表达） |
| 空态一句（`还没有消息`） | 内容（短句） | S39 | 样式说不清「这里为什么是空的」，允许一句事实 |
| 结果不确定（`结果不确定 · 正在核对`） | 内容（短句） | H2 | 决定要不要重发，样式说不清 |
| 一次操作的结果词（`完成` / `失败` / 运行中 / 等待同意） | 内容 | C3 | 与轮次状态（图形）不同：它是结果，要能读 |
| 会话标题、项目分组 | 内容 | A1 / A2 | 窗口 `Title` 与标题行各一次，不算重复 |
| 输入框占位 `输入` | 界面语 | S19 | 2 字，说明这一处能写（R6 裁决） |
| 审批三决定 `允许一次 / 一直允许 / 拒绝` | 界面语 | D3 | 不可逆动作，图标不能唯一确定；形式见 `U3-actions.md` |
| 发送 / 停止 | 界面语 | F2 | 只作读屏名与 tooltip，屏幕上不出现 |

## 4 与检查器的接口

| 检查项 | 用清单做什么 |
|---|---|
| L2（字符冒充图标） | 内容字符串里出现 `＋ ‹ › × ⋯` 时按内容放行（当前清单里没有这类字符串） |
| L6（状态词上屏） | 状态词一旦**作为字面量**画到屏幕上就是界面语，报；报错信息给出对应的信息项编号 |

JSON 字段：`id`、`match`（`exact` / `prefix`）、`value`、`item`（U1 信息项编号）、`kind`（`content` / `interface`）、`why`。

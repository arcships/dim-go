基线：左栏放会话（256）→ 标题行 48 写会话名、分支、权限、模型 → 时间线按内容上限 784 居中，用户消息右对齐、助手铺开、操作收成一行 → 输入区贴底（60–300），有排队项时上方出现队列条 → 右栏可选（280–容器−400），只放当前会话的附属内容。按 §9.9：审批出现时占据输入位，替换输入区；界面不用内部术语；流式保序、动效可关。

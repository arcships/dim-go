# U2 C2：视觉规范（首片）

Status: draft（C2 首片结果包，待组织评审）
Owner: U2 界面视觉
依据: `docs/domains/U0-design-archaeology.md` §12.5–§12.6（现役客户端的间距与字阶实测）、`docs/domains/U0-framework-baseline.md` §2.4–§2.6（框架 token 与状态能力）、`docs/ui-alignment.md` P1/P5/P6 与 §5（状态表达规则）、`docs/project-organization.md` §9.5（三层状态标准）与 §9.9（UI-1…UI-11）、`docs/domains/U1-ia.md` §5（每个状态落在哪个元素）
范围: 首片元素——标题行、时间线的四类行（用户消息、助手回复、过程摘要行、工具行）、输入区四件（编辑器、附件块、队列条、发送/停止）、审批卡、空态、错误与未知状态——的字阶、间距、颜色语义、状态样式、动效、密度与图标、可访问性、token 表。
不做: 区域划分与控件位置（U1）、触发/前置/完成/失败/断线五段与键位（U3）、view 映射与性能预算（U4）、界面代码。本文只给"看得见的值"。

预览: `docs/domains/U2-visual-preview.html`（静态、无外部依赖，明/暗与减少动效可切）；由 `scripts/u2-preview.py` 按本文 token 值生成，改 token 后重跑即可保持一致。

## 0 口径

### 0.1 单位

全部为 DIP（等同 CSS px）：字号、行高、间距、描边、圆角、图标边长、动效时长。不写设备像素；涉及清晰度的判定一律注明倍率（§6.3、§7.4 的 200% 走查）。

### 0.2 基线

现役客户端以 14px 为根字号推出 3.5 网格与 14 / 12.25 / 10.5 / 13 的字号阶（`docs/domains/U0-design-archaeology.md` §12.5、§12.6）。本文把它当作**可对照的起点**，不是必须遵守的上限：每一项沿用或改动都在 §9 台账里单列，改动必须带数值理由。

### 0.3 判定方法

每条规范只接受三种判定，写在所在小节末尾：

| 代号 | 方法 | 做法 |
|---|---|---|
| A | 数值比对 | 读 §8 的 token 表，元素用的值必须逐字相同；不得出现表外数值 |
| B | 对比度计算 | WCAG 2.1 相对亮度公式：`(L1+0.05)/(L2+0.05)`，阈值见 §7；本文表内的比值即该公式结果，重算差 ≤0.01 视为通过 |
| C | 逐项走查 | 打开 `docs/domains/U2-visual-preview.html` 的对应区块，按该区块标注的属性逐条对 |

"看起来合适""和别家一致"不作为判定依据。

## 1 字阶

### 1.1 级表

共 **7 个字号、3 个字重、11 个语义级**。界面里出现的任何文本必须落到其中一行。

| 语义级 | token | 用在哪（首片） | 字号 | 行高 | 字重 | 相对正文 |
|---|---|---|---:|---:|---:|---:|
| 正文 | `type-body` | 助手回复、用户消息、Markdown 段落、输入内容、时间线内说明行（失败原因、结果不确定） | 14 | 22.75（×1.625） | 400 | 1.000 |
| 正文强调 | `type-body-strong` | Markdown 粗体、正文里的对象名 | 14 | 22.75 | 600 | 1.000 |
| 次要 | `type-secondary` | 过程摘要行、工具行、时间、用量、标题行的附加信息、按钮标签、附件块文字 | 12.25 | 18（×1.469） | 400 | 0.875 |
| 次要强调 | `type-secondary-strong` | 摘要行里的状态词（"失败""等待你同意"）、键位提示 | 12.25 | 18 | 600 | 0.875 |
| 极小 | `type-micro` | 计数（+n/−n）、徽标、行内编号、附件大小 | 10.5 | 14（×1.333） | 500 | 0.750 |
| 代码 | `type-code` | 代码块、行内代码、审批卡里的命令 | 13 | 20（固定） | 400 | 0.929 |
| 标题行会话名 | `type-title-row` | 标题行的会话名 | 14 | 20（固定） | 600 | 1.000 |
| 对话内 h1 | `type-h1` | Markdown 一级标题 | 20 | 26（固定） | 600 | 1.429 |
| 对话内 h2 | `type-h2` | Markdown 二级标题、设置节标题 | 17.5 | 24（固定） | 600 | 1.250 |
| 对话内 h3 | `type-h3` | Markdown 三级标题 | 15.75 | 22（固定） | 600 | 1.125 |
| 对话内 h4 | `type-h4` | Markdown 四级标题 | 14 | 20（固定） | 600 | 1.000 |

按钮标签 = `type-secondary`（12.25/18/400）；主按钮与次按钮同字号，**层级靠填充色与描边区分，不靠字重**。空态、错误说明等"一行话"同样只用 `type-secondary` 或 `type-body`，不引入大字号（P7/P8：空态不靠夸张字号充场面）。

### 1.2 与基线的关系

| 项 | 基线 | 本文 | 判定 |
|---|---|---|---|
| 正文 | 14 / 22.75 / 400 | **不变** | A |
| 次要 | 12.25 / 约 15.3（1.25）/ 400–500 | 字号**不变**；行高定 18（1.469）；字重收 400，强调另设一级 | A |
| 极小 | 10.5 / 由 leading 决定 / 500 | 字号**不变**；行高定 14（1.333） | A |
| 代码块 | 13 / 20 / 400 | **不变** | A |
| 行内代码 | 0.875em = 12.25 | **改为 13 / 20** | A |
| h1 | 17.5 / ≈21.9 / 600 | **20 / 26** | A |
| h2 | 16.6 / ≈20.8 / 600 | **17.5 / 24** | A |
| h3 | 15.75 / ≈19.7 / 600 | **15.75 / 22** | A |
| h4 | 14.9 / ≈18.6 / 600 | **14 / 20** | A |
| 设置节标题 | 17.5 / ≈21.9 / 600 | 17.5 / 24，复用 `type-h2` | A |

改动理由（每条都可量）：

1. **h1 17.5 → 20**：基线 h1 : h2 = 17.5 : 16.6 ≈ 1.054，级差 0.9px 且同级字重，长文里读不出"这是一级"。新级差 h1 : h2 = 1.143、h2 : h3 = 1.111、h3 : h4 = 1.125，每级至少差 1.75px。
2. **h4 14.9 → 14**：14.9 比正文高 0.9px，与正文同字重差异不足，等于"正文加粗"。改为与正文同字号，用字重 600 + 行高 20（正文 22.75）区分。
3. **行内代码 12.25 → 13**：与代码块差 0.75px（@2x 1.5 设备像素）肉眼不可辨，却要维护两套 padding 与行高换算；统一后代码只有一档。
4. **标题行高由"约 1.25"改为整数 26/24/22/20**：15.75×1.25 = 19.69、17.5×1.25 = 21.875，多行标题与 22.75 正文行不同步，段距无法用 3.5 网格表达。改为固定整数后，标题占位与段距都可整除。
5. **保留正文 14 / 22.75**：这是现役客户端实测值（`docs/domains/U0-design-archaeology.md` §12.6），并行对照期间同一段文字换行位置可比；改动它会让所有历史截图与走查记录失效。

### 1.3 字重与字体

- 只用 400 / 500 / 600。不用 700：首片没有比 600 更强的层级，一旦需要 700 就说明层级该拆，而不是该加粗；也不混用 300（14px 中文细体在正文里发虚）。
- 字体走系统 UI 字体栈（mygo `Theme.Font = ""`）；代码用系统等宽（`Font("SF Mono, Menlo, monospace")`）；中文由 `Lang` 决定字形变体。**不内嵌字体**（体积与许可都不划算，且系统字体即平台一致性的来源）。
- 数字列（用量、耗时、计数）加 `FontFeatures("tnum")`，避免逐帧跳宽。

**判定**：任一文本元素可量到（字号, 行高, 字重）三元组且等于 §1.1 某行；行高的量法是行盒高度（单行）或首行基线到次行基线的距离（多行）。走查 §1 区块（C）。

## 2 间距节奏

### 2.1 基础单位

**基础单位 3.5，与基线一致**（`docs/domains/U0-design-archaeology.md` §12.5 的 3.5 / 5.25 / 7 / 10.5 / 14 / 21 / 28 全是它的倍数）。

理由与代价：

1. U0 的区域尺寸、C1 的线框都按 3.5 的倍数出图；换基础单位等于重测每个区域，收益只是"整数好看"。
2. 3.5 @2x = 7 设备像素，是整数；1x 下允许半像素（native 布局是浮点），判定以 2x 为准。
3. mygo 的 `Theme.Spacing` 默认 4，改成 3.5 是一行配置；代价是内置控件内边距比框架默认紧 12.5%（4→3.5），这是有意选择，不是遗留。
4. 备选（不采用）：以 4 为基准。它会让每个已测尺寸都要换算成 4 的倍数，且与 C1 线框全部错位。

### 2.2 标尺

只用七档：`space-1` 3.5、`space-2` 7、`space-3` 10.5、`space-4` 14、`space-6` 21、`space-8` 28、`space-12` 42。5.25 / 17.5 这类"半档"是**尺寸**（缩进、行高、宽度），不是间距；间距一栏不得出现它们。

### 2.3 用法（首片元素）

| 位置 | 值 | 依据 |
|---|---:|---|
| 图标与文字、按钮内图标与标签 | 7 | 与行内字符间距拉开但不分组 |
| 标记点与相邻文字 | 3.5 | 标记属于该行文字，不单独成组 |
| 行内元素之间（徽标、附件块内的按钮） | 3.5–7 | — |
| Markdown 段落之间 | 10.5 | 与消息组间距同为 10.5；基线 7 与行内间距同值，两个不同含义共用一档（改动见 §9 #21） |
| 代码块、引用块、表格上下 | 10.5 | 同上 |
| h1 / h2 上 21、下 10.5；h3 / h4 上 14、下 3.5 | — | 沿用基线（1.5em / 0.75em、1em / 0.25em 换算后一致） |
| 同一轮内消息/块之间 | 10.5 | 组内 |
| 轮次之间 | 21 | 组间，是组内的 2 倍 |
| 卡片内边距（审批卡、空态说明块、错误块） | 14 | 决策面留白 |
| 输入卡内边距 | 10.5 | 沿用基线 `p-3` |
| 队列条与输入卡之间 | 7 | UI-10：队列贴输入区 |
| 区域内容左右边距 | 14 | 沿用基线 `px-4` |

### 2.4 例外规则

**居中余量不进网格**。固定高度的容器（如 U1 定的 33px 队列条）里让文字垂直居中，上下余量 = (容器高 − 行盒高) ÷ 2，允许半档；网格约束的是元素之间的间距与内边距，不是"剩余空间均分"。

### 2.5 判定

相邻两块的行盒外边界之差必须等于 §2.3 的值（不含阴影与焦点环）；多行文本的段距按"下一段首行行盒上沿 − 上一段末行行盒下沿"量。走查 §2 区块（C）。

## 3 颜色语义

### 3.1 规则

1. 颜色只经语义 token 使用；元素里不得出现字面色值。
2. **明/暗两套同名同角色**；主题跟随系统（U1 参数）。
3. **强调色只用于"可操作 / 当前 / 进行中"**：主按钮、焦点、选中条、待决与运行中的标记。不作装饰（分隔线、普通图标、标题不用强调色）。
4. **成功 / 警告 / 危险只用于状态**，不作大面积填充：只出现在文字、图标、1px 描边上（单处填充面积 ≤ 该行面积的 15%）。
5. 状态不以颜色单独表达（§4.0 第 4 条）。
6. 每主题 20 个设计 token；另有 3 个沿用框架默认、不参与设计的颜色字段（`Inverse`、`InverseText`、`Scrollbar`）。

### 3.6 选区的使用约束

选区叠在 `surface` 上时，次要文本只有 4.38（明）/ 3.93（暗）。因此：

- 选区只作用于**正文、代码、链接**；
- **次要文本（时间、计数、徽标、状态词）设不可选**（mygo 的 `Unselectable`，把次要文本子树排除在选择范围外）；
- 代码块的选区用同一 `selection`，代码 13px 正文色不变（13.35 / 10.66）。

这是一条视觉约束，落点（哪些子树不可选）由 U3 在交互规格里写、U4 在 view 层实现。

**判定**：A + B（重算对比度 + token 值逐字一致）；走查 §3 区块（C）。

## 4 状态样式

### 4.0 固定规则

1. **只改已有元素的属性**。每个状态必须能答"用户此刻的眼睛落在哪个既有元素上"，元素归属见 `docs/domains/U1-ia.md` §5；本文不新增容器、不新增状态条、不做一状态一元素（P1、`docs/ui-alignment.md` §5）。
2. **语义态优先于视觉态**：不可用吸收悬停与聚焦，不因悬停把不可用控件点亮（`docs/project-organization.md` §9.5 第二层）。
3. 多状态并列时按固定优先级裁决：**待你决定 > 结果未知 > 失败 > 进行中 > 可用**；高优先级决定可操作性与主视觉，低优先级只作次要提示。
4. **每个状态至少两项差异**（颜色 + 形态/文字/位置），色觉障碍下不得只靠颜色区分。
5. 状态文字只补事实（对象、原因、数值），不承担"状态是什么"（P1）。
6. 本文不写状态文案措辞（归 U1 术语表与 U3）。

### 4.1 八个状态

| 状态 | 落在哪个已有元素（C1 §5） | 变化属性与具体值 | 不做什么 |
|---|---|---|---|
| **运行中** | 过程摘要行 + 助手行尾 + 发送键 | 摘要行行首 8px 实心圆 `accent-ink`；行尾光标 2×14 `accent-ink`，周期 1060ms；发送键文字变"停止"，填充仍 `accent` / `accent-on` | 不加运行胶囊、不加进度条（无真实进度；P6/P8） |
| **等待你同意** | 输入位整块（UI-1）+ 该轮摘要行 | 输入区内容整块换成审批卡（不并存）：卡面 `surface`、1px `accent` 描边、圆角 8、内边距 14；卡内主按钮 `accent` 填充；摘要行行首 16px 时钟图标 `accent-ink`，状态词 600 | 不弹模态、不与输入并置、不新增提示条（P2、UI-1） |
| **失败** | 摘要行 + 失败条目（展开内） | 行首 16px 叉图标 `danger`；摘要行文字 `text-secondary`（保持 5.75:1）；失败原因正文 `text`，**不加红字、不加底色** | 不弹窗、不加提示条、不造重试入口（`docs/ui-alignment.md` §5 动作三条件） |
| **结果未知** | 该轮消息下方说明行 | 行首 16px 叹号图标 `warning`；说明文字 `text`（14/22.75）；说明行属于本轮，不是容器 | 不标成功、不标失败、不给重试、不给核对按钮（核对进度由 D3 事实驱动，文字只陈述） |
| **不可用** | 受影响的控件/区域 | 整棵子树不透明度 0.5（框架内建），不响应悬停与聚焦；输入区另加一行原因（`text-secondary`）；禁用按钮：`surface` + 1px `border` + `text-secondary` | 不只改字色；不加"即将支持"；未接能力一律隐藏（UI-6、Q-17 待裁决时按隐藏） |
| **选中** | 左栏会话行、右栏标签 | 底色 `surface-selected`；行首 2px 宽、行高−14 高（上下各留 7）的 `accent-ink` 竖条，画在同一元素的内侧，不新增元素；文字色不变 | 不用 accent 纯色填充；不在选中行上叠加悬停色（选中优先） |
| **悬停** | 可交互面（会话行、工具行、按钮、附件块） | 背景 `surface` → `surface-hover`，120ms；文字与图标颜色不变；不位移、不缩放 | 不改变边框宽度（会引起位移）、不出现新的动作按钮（行内动作由 C1 定，出现与否不归本文） |
| **聚焦** | 可获得键盘焦点的控件 | 焦点环 2px `focus`、外偏 1px，不参与布局；仅在键盘导航（`FocusVisible`）出现；环内元素外观不变 | 鼠标点击不出现环；不用背景色冒充焦点 |

### 4.2 视觉态矩阵（`docs/project-organization.md` §9.5 第一层）

每格是"属性组 → token"；空格表示该态不改变该属性。

| 控件类 | 默认 | 悬停 | 聚焦 | 按下 | 禁用 | 选中 | 加载 | 错误 |
|---|---|---|---|---|---|---|---|---|
| 行（会话行、工具行、摘要行） | 底 `transparent`，文字 `text` / 次要行 `text-secondary` | 底 `surface-hover` | 焦点环 | 底 `surface-pressed` | 不透明度 .5 | 底 `surface-selected` + 2px `accent-ink` 竖条 | 8px 圆点 `accent-ink`（运行中） | 16px 图标 `danger` |
| 按钮（发送/停止、同意/拒绝） | 主：`accent` + `accent-on`；次：`surface` + `border` + `text` | `accent-hover` / `surface-hover` | 焦点环 | `accent-pressed` / `surface-pressed` | `.5` + 不响应悬停 | 不适用 | 文字变"停止"，不换形（无 spinner） | 不适用（错误落在说明行） |
| 输入卡（编辑器） | `surface` + 1px `border`，圆角 12 | 不变（卡不是按钮） | 1px `border-strong` + 焦点环 | 不适用 | `.5` + 原因一行 | 不适用 | 不适用（运行不阻塞输入） | 边框 `danger` + 一行原因 |
| 审批卡 | `surface` + 1px `accent` | 卡本身不响应；卡内按钮各自响应 | 焦点环落在首个可操作项 | 卡内按钮 | 提交中：主按钮 `.5` | 不适用 | 主按钮文字不变（不换 spinner），见 U3 | 卡内一行原因 `danger` |

"加载"在本文统一指**运行中**（有真实事实支撑）；框架没有控件级 loading 态（`docs/domains/U0-framework-baseline.md` §2.5.1），因此不自造 spinner 塞进按钮。

### 4.3 状态与颜色语义的边界

- `accent-ink` 同时承担"运行中 / 待决 / 选中条"，因为这三者都是"当前正在发生或当前所在"，语义一致；它们靠**形态**区分（圆点 / 时钟图标 / 竖条）。
- `success` / `warning` / `danger` 只出现在失败、未知、成功这三种结果上，不用于悬停、选中、按钮边框。
- 失败不把正文染红：错误颜色只标"这一项失败了"，正文保持可读。

**判定**：走查 §4 区块（C），每行状态的三个属性（前景 / 背景 / 形态）可量；颜色值对 §3（A），对比度对 §7（B）。

## 5 动效

### 5.1 三档时长与曲线

**三档，全部由 token 提供；代码里不得出现裸时长。**

| token | 时长 | 曲线 | 用途 | 60Hz 帧数 |
|---|---:|---|---|---:|
| `motion-fast` | 120ms | `EaseOut`（1−(1−t)³，框架 `ui.EaseOut`） | 颜色、背景、描边、不透明度、焦点环出现/消失、逐字淡入 | ≈7.2 |
| `motion-base` | 200ms | `EaseOut` | 出现/消失、折展、队列条进出、附件块增删 | ≈12 |
| `motion-slow` | 320ms | `EaseInOut`（框架 `ui.EaseInOut`） | 区域级：审批卡替换输入区、右栏开合、整屏切换 | ≈19.2 |

- **首片不用弹簧**：框架的 `Smooth/Snappy/Bouncy`（500ms 弹簧）只保留给框架内建的时间线跟随滚动，不作为我们的状态转场。理由：弹簧在"失败/待决"这类需要立刻判断的状态上会拖慢识别。
- 框架默认值对照：布局过渡 `Duration = 0` 时按 200ms（与 `motion-base` 相同）；弹簧默认 500ms（不用）。基线折叠 300ms 改为 200ms，理由是同一交互族（折展）统一到框架默认值，减少逐处手写时长。
- 时长上限：任何由状态变化引起的过渡 ≤320ms；超过即属"转场"而非"过渡"，需另行立项。

### 5.2 逐字出现

| 项 | 值 | 说明 |
|---|---|---|
| 单位 | 词（拉丁）/ 字素簇（中文） | 中文按字出，不按空格切 |
| 节奏 | 到达即出，最多落后 400ms（CatchUp） | 事实到达快时加速追平，不做固定速率打字机 |
| 淡入 | 120ms（= `motion-fast`），只改不透明度/颜色 | 不重排、不改行高、不位移（UI-4） |
| 顺序 | 严格按事实顺序逐条追加 | 折叠只改可见性，不改顺序（UI-4） |
| 完成判定 | 队列排空（markstream 的 `Revealed`） | 排空后才挂时间与操作条 |

不与"整段淡入"混用：一条消息要么逐字出现，要么整体出现（历史回看时整体出现）。

### 5.3 光标

助手正在写的行尾光标：2×14 `accent-ink`，周期 1060ms（亮 530 / 灭 530），随本轮完成消失。不用方块光标，不用渐变。

### 5.4 减少动效（UI-5）

UI-5 比框架默认更严：框架在 `ReduceMotion` 下仍让颜色与不透明度继续动（`NonMotion`），而 UI-5 要求"所有转场、逐字出现、弹簧效果退化为瞬时呈现"。

| 项 | 正常 | 减少动效时 |
|---|---|---|
| 三档时长 | 120 / 200 / 320ms | 全部 0ms（瞬时） |
| 逐字出现 | 逐单位 + 120ms 淡入 | CatchUp 0、Fade 0：随事实到达整段出现 |
| 光标 | 1060ms 闪烁 | 常亮 |
| 跟随滚动 | `FollowAnimation`（框架 Smooth） | 直接跳到底 |
| 布局与状态 | — | **不变**（UI-5：开关只影响呈现，不增减元素与状态） |

实现注意：不能只依赖框架的 `ReduceMotion` 自动摊平，必须在开关为真时把时长显式设为 0（颜色与透明度默认属于 `NonMotion`，框架会继续动）。

**判定**：C（系统"减少动效" + 预览页开关各走一遍，对比布局与状态不变）+ A（所有时长等于 token）。

## 6 密度与图标

### 6.1 密度

**中**（U1 参数）。只提供一档，不做 compact/roomy 切换。定义的是控件高度，不定义区域位置：

| 档 | 值 | 用在哪 |
|---|---:|---|
| `row-regular` | 28 | 会话行、按钮、单行输入控件 |
| `row-compact` | 24.5 | 工具行、行内小按钮、附件块内按钮 |
| `control-mini` | 21 | 徽标旁的操作、微型按钮（命中区仍 ≥24×24，§6.5） |

输入卡高度 60–300、标题行 48 属区域尺寸，见 U1，不在本文重复定义。

### 6.2 行高与图标的关系

**规则：图标盒 ≤ 行高 − 2×3.5**（至少留一个基础单位）。

| 行高 | 图标盒 | 上下余量 |
|---:|---:|---:|
| 28 | 16 | 6 / 6 |
| 24.5 | 16 | 4.25 / 4.25 |
| 21 | 12.25（仅文字级标记，不用 SVG） | 4.375 / 4.375 |

此外：图标**不单独落行**（必须与相邻文字同一行），图标与文字底边对齐改为**行盒内光学居中**。

### 6.3 图标风格与来源

| 项 | 规格 |
|---|---|
| 风格 | 线性、单色、24 网格、描边 1.5 |
| 尺寸档 | 16（行内、按钮、工具行状态位）、20（空态、区块级）；**不用 14 / 18** |
| 描边落地 | 16 → 1.0px、20 → 1.25px（按 24 网格等比缩放）；不把小图标缩到 14 以下（14 时描边 0.875px，1x 屏会发虚） |
| 实心 | 界面不用实心图标；实心只出现在品牌标志与 8px 状态点（点由 `Box` + 圆角画，不是图标） |
| 来源 | 界面图标 **Heroicons v2**（MIT，接入时按 v2.2.0 取并逐个核对）；AI/供应商标志 **ailogo**（MIT，商标仅用于识别那家供应商）；不用 emoji 当界面图标 |
| 打包 | SVG 内嵌（`go:embed`）+ `ui.MustParseSVG`，离线可用；MIT 声明进第三方记录 |
| 颜色 | 运行时由 `ui.Icon` 用文字色重绘（它会忽略文件里的颜色），因此图标只给结构，颜色来自 §3 |

已核对的事实（重跑同一条命令即可复核）：

- Heroicons 24/outline 的文件为 `viewBox="0 0 24 24"`、`stroke-width="1.5"`、`stroke="#0F172A"`（原始文件取自 `tailwindlabs/heroicons` 仓库 `src/24/outline/`）；
- `tailwindlabs/heroicons` 的 GitHub 许可字段为 MIT；
- Lucide 的 `LICENSE` 是 ISC + 一组派生自 Feather 的 MIT 图标（GitHub 许可字段因双许可显示为 Other），因此不选它做统一图标集，避免双声明。

### 6.4 图标与状态标记的尺寸

| 用途 | 尺寸 | 形态 |
|---|---:|---|
| 行内动作图标（复制、展开、关闭） | 16 | 线性 |
| 状态位（失败、未知、等待、成功） | 16 | 线性：叉 / 叹号 / 时钟 / 勾 |
| 运行中 | 8 | 实心圆（不是图标，不带语义形状） |
| 空态 | 20 | 线性 |
| 品牌标志 | 16 或 20 | 品牌原形（ailogo，可能是彩色） |

### 6.5 命中区域

视觉尺寸与命中区域分离：16px 图标按钮的命中区 ≥24×24；21px 微型按钮外扩到 24×24（透明内边距），视觉尺寸不变。

**判定**：A（尺寸逐项对表）+ C（走查 §6 区块，量图标盒与行高）。

## 7 可访问性

### 7.1 对比度目标与实测

| 类别 | 目标 | 实测最小值 | 位置 |
|---|---:|---:|---|
| 正文与标题（全部字号） | ≥4.5 | 4.56（明 `success` 作文字对 surface）/ 5.38（暗 `danger`） | §3.2、§3.3 |
| 次要文本 | ≥4.5 | 5.75（明）/ 5.81（暗），悬停面 5.22 / 4.98 | §3.2、§3.3 |
| 强调色作文字（链接、状态词） | ≥4.5 | 6.10（明）/ 7.13（暗）`accent-ink` | §3.2、§3.3 |
| 填充上的文字 | ≥4.5 | 5.17（`accent-on` 对 `accent`） | §3.2、§3.3 |
| 焦点环 | ≥3 | 4.13（明，落选中面）/ 4.78（暗，落选中面） | §7.2 |
| 非文本图形（状态图标、选中条） | ≥3 | 5.35（明选中条）/ 5.82（暗） | §4.1 |
| 单独承担识别作用的控件边框 | ≥3 | 3.34（明 `border-strong` 对 surface）/ 4.41（暗） | §3.2、§3.3 |

**两处有意保留的例外**（写明理由，避免被当成疏漏）：

1. `accent` 填充在暗色 `surface` 上的边界 2.88。该按钮有文字标签，识别由标签承担，边界不承担识别；无文字标签的图标按钮一律不用 `accent` 纯色填充，改用 `border-strong` 轮廓 + `Label`。
2. 禁用态不透明度 .5（明等效 3.31 / 暗 4.55）：WCAG 明确豁免禁用控件。

### 7.2 焦点环

- 2px 环 + 1px 外偏移，颜色 `focus`，**不参与布局**（画在元素外侧，出现时不引起任何位移）。
- 只在键盘导航时出现（`FocusVisible`）；鼠标点击不出现。
- 与相邻两侧的对比度：明 4.70（对 surface）/ 4.27（对悬停面）；暗 5.86 / 5.02，均 ≥3。
- 环与元素边框之间留 1px 间隙，使"环"与"边框"不混为一个更粗的边。

### 7.3 目标尺寸

交互目标最小 24×24（WCAG 2.2 AA），行级控件 28；相邻目标之间的间距 ≥7，避免误触（尤其 24.5 工具行上的行内按钮）。

### 7.4 文本缩放

系统文本缩放 100–200%（框架 `Preferences.TextScale`）下：

- 所有行高用倍数（正文 1.625）或固定整数余量（标题），不写死"文字区高度 = 行数 × 22.75"；
- 200% 时状态文字不得截断（走查项）；
- 图标盒随行高一起放大（按行高比例），不按字号单独换算——否则会得到 12.25 / 22.75 这类非整数描边。

### 7.5 高对比度

`Preferences.HighContrast` 为真时：`border` 取 `border-strong`；`text-secondary` 取 `text`；焦点环加宽到 3px。其余 token 不变。

### 7.6 色觉

每个状态至少两项差异：运行中（圆点 + 文字"正在运行"）、失败（叉 + 状态词）、未知（叹号 + 说明行）、待决（时钟图标 + 卡片存在）、成功（勾）。红绿不并在同一元素上区分两个状态。

**判定**：B（逐格重算）+ C（Tab 走查焦点、200% 缩放走查、系统"增强对比度"走查）。

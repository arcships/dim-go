## 1 方案 A：过程收成一行

**解 T2。** 线框：[wireframes/a.html](wireframes/a.html)

### 1.1 结构描述

基线不变；一轮里的全部操作与中途说明收成一行**轮次组头**，只有最终回复铺开；组头写这一组做了什么（动作与对象），状态只由行首图标承担，因此它自己表达运行中、等待同意、失败三种形态，并且**必须可展开**：展开后按发生顺序逐条列出每一次操作。

组头不是一个状态词，而是一句**内容**：`✓ 读取 composer.go · 改动 composer.go · 执行 go test ./...`（行首图标表达状态、不写状态词；没有动作的纯对话轮不出组头）。计数与文件清单属于明细，收进展开：展开后第一行写「N 个操作 · 改了 N 个文件」，下面每条形如 `3 · 执行 · go test ./... · 失败`，失败条目下面加一行原因；展开状态按会话记住。时长不进界面（§9.0 取向 2）。这一行的**入口是内容本身**（UI-16）：点内容即展开或收起，方向指示紧跟内容并随开合旋转，没有「展开」「收起」文字。

### 1.2 偏离台账（2 处）

| # | 常规做法 | 改成什么 | 代价 |
|---|---|---|---|
| A-1 | 每个操作一行摘要（读一行、改一行、跑一行），基线如此 | 一轮的全部操作收成一行**组头**（`✓ 读取 composer.go · 改动 composer.go · 执行 go test ./...`）；计数全部进展开，展开后按顺序逐条列出（序号、动作、对象、结果，失败带原因） | 折叠时看不到做了多少；组头回答"这一轮做了什么"，要判断工作量必须展开 |
| A-2 | 运行中 / 出错由各自的操作行或提示承载 | 同一行换形态：行首 8px 圆点（运行中）/ 时钟（等待同意）/ 叉（失败）/ 对勾（完成），只换图标与颜色，不写状态词、不加时长；不新增提示区 | 组头只有一行，多个状态同时成立时按优先级取一个（等待同意 > 失败 > 运行中 > 完成） |

### 1.3 三行说明（按状态）

| 状态 | 主次排序 | 重复单元 | 面积分配理由 |
|---|---|---|---|
| 默认态（组头折叠） | ① 最近一轮 ② 输入区 ③ 组头 | 一轮 = 用户消息 + 助手消息 + 组头 | 时间线 728 / 输入 124 / 标题 48；内容左缘对齐，左栏 20% |
| 组头展开 | ① 展开后的条目列表 ② 那一轮的回复 ③ 输入区 | 第一行是计数「N 个操作 · 改了 N 个文件」；其下一条操作一行：序号 · 动作 · 对象 · 结果；失败下加 18px 原因行；不写时长 | 展开占 4 行（约 91px）从时间线借，不改变宽度 |
| 动效关闭 | 与折叠态一致 | 与折叠态一致 | 与折叠态一致；只去掉逐字出现与转场 |
| 运行中 | ① 正在写的那段回复 ② 助手的行尾光标与组头的行首圆点 ③ 队列条 | 同上；运行态不加行，只给组头换行首图标 | 队列条 33 从时间线借 |
| 等待你同意 | ① 审批卡 ② 组头的行首时钟图标 ③ 队列仍在输入区上方 | 审批卡三段：要做什么 / 影响 / 决定 | 输入区整块换成审批卡（110→150），时间线 728→702 |
| 出错/不确定 | ① 组头的行首叉图标 ② 消息下的结果说明（「结果不确定」是唯一保留的文字状态） ③ 其余历史 | 同一套标记：叉图标、次要灰度、一行说明；失败条目与原因在展开里 | 不加新区域 |
| 长历史 | ① 当前轮 ② 上一页 ③ 输入区 | 一行一轮 | 上一页 28px，按需 |

### 1.4 信息层级

一眼：最近一轮的回复与轮次组头；等待同意时是审批卡。第二眼：轮次结构、队列条。按需：组头展开后的每次操作、右栏（文件/改动/后台/目标）。

### 1.5 关键交互

| 动作 | 触发 → 看到什么 → 结果 |
|---|---|
| 发送 | 按发送 → 输入区清空、轮尾出现用户消息与回复流式 → 回执后行固定（`session.submit`） |
| 打断 | 审批到达 → 输入区整块换成审批卡，同时那一行写"等待你同意" → 决定后卡消失、输入区回来（`approval.respond`；一直允许先写规则 `permission.set_rules`） |
| 会话切换 | 点左栏会话 → 主区整块重建，不闪空 |
| 展开/收起 | 点组头的内容块（行首图标、文字、方向指示都算）或按 → → 组头下方按发生顺序列出条目（1、2、3……），方向指示转向下方；展开状态按会话记住 → 再点内容块收起。行内没有「展开」「收起」文字入口（UI-16） |
| 出错与不确定 | 操作失败 → 组头行首叉图标，展开后失败条目下写"原因：权限不足，命令没有执行"；提交超时 → 消息下加一行"结果不确定…正在核对"，不出现重试按钮 |

### 1.7 状态如何附着

| 状态 | 元素 | 属性 | 不做什么 |
|---|---|---|---|
| 运行中 | 助手消息 + 组头 + 发送键 | 末尾光标；组头行首 8px 实心圆 `accent-ink`；键文字变「停止」 | 不加运行胶囊、不写状态词 |
| 排队中 | 队列条 | 出现 / 消失，33px | 不加徽标 |
| 等待同意 | 输入区整块 | 内容换成审批卡（110→150） | 不与输入并存；不用模态 |
| 工具失败 | 组头 | 行首 16px 叉图标 `danger`，组头文字转次要灰度；失败条目与原因在展开里 | 不弹窗、不加提示条、不造重试、不写状态词 |

| 断线 | 输入区 + 时间线底部 | 输入区不可用；底部一行断点 | 不另立连接指示 |

### 1.8 可见性取舍

首屏：时间线、输入区、标题行；等待同意时审批卡。按需：那一行展开、右栏、队列条、上一页。不出现：状态条、活动条、任务中心、重试入口。

### 1.9 放弃什么

- 放弃"过程顺次可见"：要看每一步必须展开。
- 放弃中途说明的默认呈现：它被并进那一行，只能展开看。
- 放弃一行的表达力上限之外的信息：一行只放"动词 + 数量"。

## 2 方案 B：轮次索引

### 2.1 结构描述

### 2.2 偏离台账（1 处）

### 2.3 三行说明（按状态）

| 状态 | 主次排序 | 重复单元 | 面积分配理由 |
|---|---|---|---|
| 默认态 | ① 最近一轮 ② 输入区 ③ 索引条 | 一轮 = 用户消息 + 助手消息 + 每个操作一行 | 索引 22 / 内容随宽度 / 输入 124；索引只在长会话出现 |

### 2.4 信息层级

一眼：最近一轮。第二眼：操作行结果词、索引针位置。按需：右栏、展开细节。

### 2.5 关键交互

| 动作 | 触发 → 看到什么 → 结果 |
|---|---|
| 发送 | 按发送 → 清空、流式 → 回执后固定（`session.submit`） |
| 打断 | 审批到达 → 输入区换成审批卡，对应操作行写"等待你同意" → 决定后恢复（`approval.respond`） |
| 会话切换 | 点左栏会话 → 重建；索引针按新会话轮次重排 |
| 出错与不确定 | 失败行 ✕；提交超时加一行说明，不出现重试 |
| 展开操作 | 点操作行 → 该行下加结果详情；失败时加一行原因 → 再点收起 |
| 跳轮（本方案特有） | 点索引针 / ↑↓ → 滚到该轮顶部并高亮该轮；不改变会话 |

### 2.6 附属对象落点

同 A 的落点表（目标在标题行、改动与后台在右栏、文件在展开与右栏）；差异是改动计数挂在每个操作行末尾，而不是合成一行。

### 2.7 状态如何附着

| 状态 | 元素 | 属性 | 不做什么 |
|---|---|---|---|
| 运行中 | 操作行 + 助手消息 + 发送键 | 行内"进行中"；末尾光标；键文字「停止」 | 不加胶囊 |
| 排队中 | 队列条 | 出现/消失 | 不加徽标 |
| 等待同意 | 输入区整块 + 操作行 | 换成审批卡；行内"等待你同意" | 不并存 |
| 工具失败 | 操作行 | 行首 ✕、文字转 #999 | 不弹窗、不造重试 |
| 结果不确定 | 消息下说明行 | 多一行 | 不标记成功 |
| 当前轮（索引） | 索引针 | 加粗、颜色加深 | 不新增图例 |
| 断线 | 输入区 + 底部 | 不可用 + 一行说明 | 不另立指示 |

### 2.8 可见性取舍

首屏：时间线、输入区、标题行；长会话时索引条。按需：右栏、展开、上一页。不出现：状态条、活动条、任务中心、重试。

### 2.9 放弃什么

- 放弃 22px 的时间线宽度。
- 放弃"索引随时存在"：≤5 轮不出现，短会话没有这个能力。
- 放弃用索引表达"哪一轮有问题"：针只表示位置，不承载状态（否则会变成状态容器）。

### 2.13 可实现性

## 3 横向比较

### 3.1 一句话区别

| 方案 | 解哪个张力 | 一句话 | 偏离 |
|---|---|---|---|
| A 轮次组头 | T2 | 一轮只看一行内容总览，点开才逐条 | 2 |
| B 轮次索引 | T6 | 长会话左缘一排针，直接跳到某一轮 | 1 |

### 3.2 同场景差异

| 场景 | A | B |
|---|---|---|
| 默认态 | 一轮三行（你 / 它 / 组头） | 一轮多行（你 / 它 / 每个操作一行）+ 索引 |
| 运行中 | 组头行首圆点 | 操作行行首标记 |
| 等待同意 | 同一张审批卡 | 同一张审批卡 |
| 出错 | 组头行首叉图标 | 失败的操作行带叉图标 |
| 长历史 | 上一页 | 上一页 + 索引针 |

### 3.3 比例处理

| 方案 | 比例上做了什么 | 代价 |
|---|---|---|
| A | 不改横向，只改时间线内的行数（折叠时一轮 3 行；展开时 +4 行/条） | 折叠时过程不可见 |
| B | 时间线左缘 22px 给索引；内容仍左缘对齐 | 内容实际宽度 −22px |

### 3.4 淘汰线自检

| 淘汰线 | A | B |
|---|---|---|
| 虚构动作/状态 | 无 | 无 |
| 新增状态容器 | 无 | 无（索引是导航，不承载状态） |
| 模态承载非阻塞事务 | 无 | 无 |
| 以"常见做法"论证 | 无 | 无 |
| 首屏铺开全部 | 无 | 无 |
| 界面自攒事实/乐观更新 | 无 | 无 |
| 偏离 >2 处 | 2 | 1 |
| 违反 §9.9 | 无 | 无 |

### 3.5 共同未决

见 §0.6。另：A 的"一行里同时表达做了什么与卡在哪"需要在 C1 定出字数上限；B 的索引在虚拟列表下的位置稳定性需在 C4 验证。

## 4 被删掉的候选

| 候选 | 为什么删 |
|---|---|
| 审批在输入区上方另占一层 | 违反 §9.9 U1（审批占据输入位，不并存） |

| 工具失败后的"重试"/"重新生成" | 协议无此能力；写入不自动重发 |

| 常驻状态条 / 活动条 | P1、Q-9、Q-19 |

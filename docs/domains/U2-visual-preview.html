U2 C2 · 视觉 token 预览

v2 默认优先：字号比例、行高、间距基准、圆角、动效一律取 mygo 默认；只有 AA 门槛、实测证据与 UI 需求允许改。预览只示样式，不代表布局与控件位置（布局归 U1/U3）。

判定方式：数值对 §8 的 token 表；对比度按 WCAG 2.1 相对亮度公式重算；每个区块下方给出该区块的可量属性。所有尺寸是最小可复现单位，缩放窗口不改变任何数值。

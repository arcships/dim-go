# 设计基线（参考产品运行时实测）

本文件只给**常量**：值、来源、适用范围。不给需求条目、不给验收判定、不改任何需求文档。

## 0. 口径

| 项 | 口径 |
|---|---|
| 计量单位 | CSS px。DOM 采集视口 `1030×725`；截图 `2060×1450`（2×），DOM 坐标 ×2 = 截图像素。 |
| 基准字号 | 根 `font-size` = `--dimcode-ui-font-size` = **14px**（`<ref>/packages/desktop/packages/renderer/src/styles/global.css:166,390`）。因此 rem 尺度的东西全部按 **0.25rem = 3.5px** 缩放：间距、控件高、圆角、字号都是 3.5 的倍数（常见非整 px：10.5、17.5、24.5、31.5）。UI 字号可选 12/13/14/16/18（`<ref>/…/src/appearance/index.ts:15`），换档时本表 px 值按 `px × 新字号 / 14` 同比缩放。 |
| 取色 | 截图 PNG 带 P3 类 ICC profile，直接读像素得到的是 P3 数值（偏灰）。取值一律先做 ICC → sRGB 转换。校验：账户页主按钮直读 `#42894c`，转 sRGB 后 `#339751`，与 `--primary` 的 oklch 换算值 `#349651` 一致。 |
| 外观范围 | 仅默认外观（非 retro skin）。明/暗两套。 |
| DOM 证据 | `docs/domains/requirements/runtime/**/*.json`（201 个状态，60483 个节点）。下文的「DOM 实测」都指这些文件里的 `x/y/w/h`；同名 `*.png` 是同一状态的截图。 |
| 源码证据 | 参考产品源码记作 `<ref>/<相对路径>:<行号>`，相对 `<ref>/packages/desktop/packages/renderer/src`（另有标注者除外）。 |

## 1. 间距

### 1.1 档位与实际使用分布

统计口径：全部 DOM 快照里，按「元素 × 状态文件」去重后的 Tailwind 间距类（`p*/m*/gap*/space-*`）共 34996 次，换算 `n × 3.5px`。

| 档位 | 实际 px | rem | 占比 | 典型用途 | 来源 |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 9.5% | 图标与文字同排、相邻块贴合（`gap-0`/`space-y-0`） | 类名统计 |
| 最小 | **3.5** | 0.25 | 46.2% | 图标↔文字 `gap-1`；行内上下 `py-1`/`pb-1`；列表项内 `px-1` | 类名统计 |

| 区块+ | **17.5** | 1.25 | 1.1% | 状态栏左右 `px-5`；`space-y-5` | 类名统计 |

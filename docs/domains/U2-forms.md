Owner: U2 界面视觉

判据只有一句（§9.0 A0/D0）：**看的人要在多短的时间里认出"这是什么、什么状态、下一步做什么"**。元素越少不是目标；识别成本最小才是。形式按控件选（UI-23）。

## 0 方法

- **四种形式都合法**：纯图标、图标 + 文字、纯文字、样式（形状 + 颜色）。没有"哪种更高级"，只有"这个控件该用哪种"。
- **四个变量定形式**（§9.0「形式的选择」）：后果（可逆 / 影响面）、频率（高 / 低）、空间（工具栏 / 行内 / 表单 / 浮层）、词形成熟度（有约定俗成的形状 / 没有）。
- **选择表**（取自 §9.0）：高频 + 词形成熟 + 空间紧 → 纯图标 + tooltip（名称 + 快捷键）；高后果 / 不可逆 / 同族多选 → 图标 + 文字（必要时加确认）；低频 / 新概念 / 无稳定词形 → 纯文字（短句）；状态与属性 → 样式，必要时补词。
- **只禁止一件事**：用文字替代结构（用句子说状态、用提示句代替禁用、用标签代替位置）。
- **谁说的**：界面上每个字问一句"这个字是谁说的"。内容如实呈现；界面语按上表选形式。
- 每条形式都要给理由，并写出被否掉的替代形式；没有理由的条目视为没设计（X19），说不出理由的视为 X22。


## 1 形式库 v1（18 条：16 类 + 发送槽与审批决定的独立条目）

格式：信息类型 → **形式 + 理由**（后果 / 频率 / 空间 / 词形）→ 选定表达 → 被否掉的替代形式与否决理由 → 变化规则 → 退化规则。

| # | 信息类型 | 形式 | 理由（后果 / 频率 / 空间 / 词形） | 选定表达 | 否掉的替代形式（理由） | 变化规则 | 退化（窄窗 / 断线 / 长内容） |
|---|---|---|---|---|---|---|---|
| F1 | 会话身份（我在哪） | 纯文字 | 内容（会话名是事实）· 低频 · 空间充足 · 词形成熟（文档标题） | 标题行左端一行 14px/600 的会话名；左栏行加粗+面差表示当前会话 | 只靠左栏高亮（左栏可收成 12px 条，位置感会丢）；窗口标题（不在窗口里可见） | 切换会话瞬时换字；窗口 `Title` 同步给窗口管理器 | 窄窗仍是这一行；长标题单行截断，悬停提示给全名 |
| F2 | 轮次组头（这一组做了什么） | 图标 + 文字 | 状态是高频识别（→图标）· 内容是动作与对象（→文字）· 行内空间 · 组头没有约定俗成的形状（→文字参与识别） | 行首 16px 状态图标 + 内容短语（动作 · 对象）+ 紧跟其后的 16px 方向指示；宽度够时给全量，不够时**按对象**截断 | 状态词（「完成」）作表头（§9.0 A2 重复表达）；计数与时长常驻（识别成本换不来判断）；按字符硬截（会留下「执行 go…」——动作留下、对象没了，用户反而不知道跑了什么） | 动作集合变化时短语跟着变；开合只转方向指示 | **退化（R7）**：先量可用宽度（MeasureText），超宽才截；截断顺序是「去掉最后一个动作组」→「对象截到第一段（命令取第一个词、路径取末段）」→「按字符收」，动作与对象的第一段一定留住；悬停提示与读屏描述给全量；没有动作的轮不出组头 |

**空输入框的「这里能打字」（R6）**：二选一里选了**最小占位「输入」**（2 字，≤4 字上限），不是「默认聚焦让光标常驻」。

- 理由：占位在静态截图与第一次扫视里都可见；默认聚焦会让「看不看得见」取决于光标闪烁周期（A0：识别成本不能随时刻变化）。占位在第一个字符键入时消失，不进入内容通道。
- 代价：多 2 个字的界面语；它说明的是「输入框这一处能写」，与输入区的位置不重复。
- 交互侧（`U3` §3.2 的 F16 条）：打开会话不强制聚焦输入区；`Cmd+L` 仍是聚焦入口。

**全屏一致**：同一类信息在所有状态、所有宽度用同一形式；同一动作只有一个图标（F16）。

## 7 形式检查与验收记录

形式检查**按控件做**（§9.14 第 0/2 层、D5），不做全局遮字：每个控件回答"为什么是这种形式"，并把理由写进 §1/§2。检查表：

| 控件 | 形式 | 后果 | 频率 | 空间 | 词形成熟 | 结论 |
|---|---|---|---|---|---|---|
| 发送 / 停止 | 纯图标 | 可逆（可重发） | 高（每轮） | 行末紧 | 成熟（箭头 / 方块） | 纯图标 + tooltip（名称 · 快捷键） |

| 结果不确定 | 图标 + 文字 | 决定发不发 | 低 | 行内 | 无稳定词形 | 叹号 + 短句 |
| 空态 | 图标 + 文字 | 无 | 低 | 居中 | 无稳定词形 | 气泡 + 一句事实 |
| 左栏入口 | 纯图标 | 可逆 | 高 | 紧 | 成熟 | 纯图标 + 读屏名 |
